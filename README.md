# Main Feature

Main Feature is a movie review web application built as a personal project to develop and demonstrate my front-end development skills.

The project was originally created using vanilla JavaScript, HTML, and CSS and has since been migrated to React. I am continuing to expand the application with additional functionality while learning and applying modern React development practices.

## Technologies

- React
- JavaScript
- HTML
- CSS
- Vite

## Features

- Create and display movie reviews
- Component-based React architecture
- State and props for managing user input and communication between components
- Responsive user interface

## Project Development

Main Feature began as a vanilla JavaScript project and was later rebuilt using React. This progression is preserved in the repository's Git history to document the development of the project and my transition from vanilla JavaScript to component-based React development.

## Status

Currently in development. Additional features and improvements are being added.
